# Материалы из предыдущего чата

Исходный запрос: проанализировать сайт KAIZEN и сделать Telegram-бота в новом HTML-формате, в цветах и стиле сайта, который знакомит с командой, прогревает и помогает оставить заявку на разработку. В текущем чате уточнено: самостоятельный продукт с новым ботом, репозиторием и хостингом; существующая Mini App сохраняется.

## Источники

- [kaizenteam.xyz](https://kaizenteam.xyz/) — успешно получен по HTTPS при текущей разработке.
- [Figma «Kaizen_сайт»](https://www.figma.com/design/Rfq6XDqcp7FIN215Vx4o7O/Kaizen_%D1%81%D0%B0%D0%B9%D1%82?node-id=0-1) — ссылка восстановлена из исходного сообщения. Прямые инструменты Figma `create_session`, `get_design_context`, `get_screenshot` вернули отказ в доступе подключённому аккаунту. Содержимое макета не использовано как будто оно получено; соответствие ему не заявляется.
- [Оригинальный логотип](https://kaizenteam.xyz/wp-content/themes/main/img/logo.svg) — скачан без изменения в `reference/logo.svg`, показан в предпросмотре.
- [CSS шапки сайта](https://kaizenteam.xyz/wp-content/themes/main/css/header.min.css) — сохранён в `reference/site-header.css` для фиксации исходных цветов. Это справочный материал, не CSS виджета.

## Адаптация под ограничения Telegram

Каждый виджет не превышает 32 KB исходного и 4096 байт zlib-сжатого HTML. Поэтому длинная страница сайта представлена переключаемыми экранами; растровые изображения и внешние шрифты не загружаются. В виджетах используются разрешённый системный шрифт, тематические CSS-переменные Telegram и брендовый синий. Описание задачи вводится обычным ответом в чат: текстовые поля в Widgets API отсутствуют.

Код старой Mini App читался только для восстановления ранее проверенных материалов. Файлы, настройки, токен, webhook и Vercel-проект `codexKaizenbot` в этой работе не изменялись.
